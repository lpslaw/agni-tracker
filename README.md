# AGNI case tracker (draft for comment)

Static draft of the post-AGNI deprivation of liberty table for the 39 Essex Mental Capacity Resource Centre.

`index.html` is generated by `build_table.py AGNI_case_tracker.xlsx --draft` (source of truth: the workbook in the Claude project folder `agni-case-tracker/`). Do not edit `index.html` by hand; rebuild and replace it.

The site shows only rows approved for publication and can be indexed by search engines. It is linked from the 39 Essex Chambers AGNI page.
